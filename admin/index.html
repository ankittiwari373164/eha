Setup guide

  1. Go to api-console.zoho.com (use your region’s domain, e.g. api-console.zoho.com.au).
  2. Add a Server-based Application. Homepage: your site URL.
  3. Authorised redirect URI — copy exactly:
  4. Paste the Client ID & Secret here, choose your data centre and Save.
  5. Click Connect with Zoho and approve access.
  6. Click Test, then enable auto-sync.

Alternative: create a Self Client, generate a code with scope ZohoCRM.modules.leads.ALL,ZohoCRM.users.READ, exchange it for a refresh token and paste it above.

Leads are upserted by email, so re-syncing updates the existing Zoho record instead of creating duplicates.
